## 실행 방법

1. `HW6` 폴더에서 Jupyter 노트북 `hw6.ipynb`를 열고, 커널을 재시작한 뒤 `Run All`을 실행한다. `sales_clean.csv`로 모델을 학습하고 `sales_model.pkl`을 생성한다.
2. 가상환경을 활성화한 상태에서 `HW6` 폴더로 이동해 다음 명령으로 서버를 실행한다.

   ```bash
   python -m flask --app app run
   ```

3. 브라우저에서 [Swagger UI](http://127.0.0.1:5000/api/docs)를 열고 `POST /api/sales/predict`에 `{"quantity": 40, "unit_price": 200000}`을 입력해 실행한다.

## 단계 ③ 선형 회귀에 qp를 추가한 이유

수량과 단가만 넣은 선형 회귀는 두 변수에 각각 가중치를 곱해 더하므로, 총액을 결정하는 `수량 × 단가`를 직접 표현할 수 없다. 그래서 테스트 R²가 0.862였다. 두 변수의 곱을 `qp`라는 입력 특성으로 추가하면 총액을 계산하는 규칙을 표현할 수 있어 테스트 R²가 1.000이 됐다.

## 단계 ⑤ 결정 트리의 최대 깊이 선택

5-fold 교차검증에서 `max_depth=12`와 깊이 제한이 없는 트리의 평균 R²가 소수 셋째 자리까지 모두 0.995였다. 테스트 R²도 둘 다 0.994였고, 깊이 12인 트리의 잎 노드 수가 781개로 제한이 없는 트리의 800개보다 적었다. 따라서 비슷한 성능을 유지하면서 구조가 더 단순한 `max_depth=12`를 선택했다.

## 단계 ⑦ API에 사용할 모델 선택

API에는 `qp`를 추가한 선형 회귀 모델을 사용했다. 수량 40개와 단가 200,000원의 실제 곱은 8,000,000원이고, 선형 회귀 모델도 8,000,000원을 예측했다. 교안의 비교 예시에서 깊이 8인 결정 트리는 7,362,301원을 예측했으므로, 이 입력에서 실제 총액을 정확히 재현한 선형 회귀 모델을 선택했다.
